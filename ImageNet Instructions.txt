2. Check space. You need roughly 320GB free during setup — 145GB of tarballs plus the extracted tree:

df -h ~; nvidia-smi --query-gpu=name,memory.total --format=csv
3. Download ILSVRC2012_img_train.tar and ILSVRC2012_img_val.tar after registering at image-net.org.

4. Extract into the layout the splits expect — one parent directory holding both train/<wnid>/ and val/<wnid>/. The validation tar unpacks as 50,000 loose files, so they need sorting into per-wnid folders with the standard valprep.sh.

5. Point at it and confirm:

export IMAGENET_LT_ROOT=/path/to/imagenet
python run_table.py --check          # ImageNet-LT should flip to READY
If the layout is wrong, the loader says so immediately with the prefix it expected, rather than failing on the first batch after building the model and diffusion pipeline.

6. Smoke test, then the real run:

python run_table.py --dataset imagenet_lt --seeds 1 --rounds 1 --no-stable-diffusion
tmux new -s imagenet
python run_table.py --dataset imagenet_lt --seeds 1
If that card has less than about 24GB, batch 256 with ResNet-50 at 224 will not fit. Use --batch 128 --lr-scale 0.5 — linear scaling keeps it an honest approximation of the protocol, and note the deviation when you report it.
